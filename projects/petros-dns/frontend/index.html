راهنمای تنظیم روی کنسول و دستگاه‌ها

🎮 پلی‌استیشن ۵ (PS5)

Settings > Network > Settings > Set Up Internet Connection > انتخاب شبکه > Advanced Settings > DNS Settings = Manual و آی‌پی بالا را وارد کنید.

🎮 ایکس‌باکس (Xbox Series X/S)

Settings > General > Network settings > Advanced settings > DNS settings > Manual و آی‌پی دی‌ان‌اس پتروس را در فیلد Primary وارد کنید.

💻 کامپیوتر (Windows / macOS)

تنظیمات شبکه > Adapter Options > Properties IPv4 > وارد کردن دستی Primary DNS برای کل سیستم بدون نیاز به فیلترشکن.
